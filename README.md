An entry for make.fun's "Unsent: The Micro-Confession Sprint" — one micro-confession in exactly two parts: a To: line naming who it was meant for, and the unsent message itself, one line written exactly as it was typed. A message to a landlord about a tap promised in March that still drips at 3 a.m., and why it stayed in drafts.

## Run it

```sh
node main.ts
```

This writes the entry to `/output/entry.txt` (pass a path as the first argument, e.g. `node main.ts ./entry.txt`, to write elsewhere). Node 22, standard library only, no network — running it twice produces byte-identical output.

## The entry

The program writes exactly two lines, 152 characters in total — inside the competition's 1–260 character gate, with the message itself at 135 characters:

```text
To: my landlord
The tap you said you'd fix in March still drips at 3 a.m. and I stopped asking because I can't afford to be the tenant you don't renew.
```

No explanation follows the message; the reason it stayed in drafts is felt in the words, not stated.
